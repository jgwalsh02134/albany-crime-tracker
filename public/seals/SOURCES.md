# Agency seal sources

This directory contains **official** agency seals/logos used by the Agencies page (`/seals/{id}.png`).

- **Format**: PNG
- **Target size**: 1024×1024 (minimum 512×512)
- **Rendering**: Prefer official SVG/vector sources when available; otherwise use the highest-resolution official raster source.
